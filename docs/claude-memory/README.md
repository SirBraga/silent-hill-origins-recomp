# Anotações das sessões no Mac

Cópia das anotações de memória que o Claude acumulou trabalhando neste projeto no Mac (até 2026-10-15). Cada arquivo
é um fato: uma regra do usuário, uma armadilha encontrada, como medir algo. `MEMORY.md` é o índice. Parte delas
fala do *Black* (`black-decomp`), o projeto irmão de onde vieram o runtime e o renderizador.

Numa sessão nova, ler o índice e os arquivos que tocam no assunto em andamento. O que estiver desatualizado deve ser
corrigido aqui (e no `CLAUDE.md`), não repetido.
